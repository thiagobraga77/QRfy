

# QRfy

A simple and modern **QR Code Generator** built with **HTML, CSS, and JavaScript**.

QRfy allows users to enter a URL or text and instantly generate a QR Code that can be scanned using a smartphone or other compatible device.

## 🚀 Features

* Generate QR Codes from URLs or text
* Simple and intuitive interface
* Fast QR Code generation
* Works directly in the browser
* No installation required

## 🛠️ Technologies

This project was developed using:

* **HTML5** — Page structure and content
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic and QR Code generation

## 💻 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/QRfy.git
```

### 2. Enter the project folder

```bash
cd QRfy
```

### 3. Run the project

Since QRfy is a front-end project, you don't need to install any dependencies.

Simply open the `index.html` file in your browser.

You can also use **Live Server** in Visual Studio Code for a better development experience.

## 📱 How to Use

1. Open the QRfy application.
2. Enter a URL or text in the input field.
3. Click the button to generate the QR Code.
4. The generated QR Code will be displayed on the screen.
5. Scan the QR Code using your smartphone.
